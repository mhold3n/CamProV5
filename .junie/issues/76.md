Updates `nalgebra-sparse` from 0.9.0 to 0.11.0
<details>
<summary>Changelog</summary>
<p><em>Sourced from <a href="https://github.com/dimforge/nalgebra/blob/main/CHANGELOG.md">nalgebra-sparse's changelog</a>.</em></p>
<blockquote>
<h2>[0.11.0]</h2>
<p>The <a href="https://nalgebra.rs">website</a> has been fully rewritten and gives a good
overview of all the added/modified features.</p>
<p>This version is a major rewrite of the library. Major changes are:</p>
<ul>
<li>Algebraic traits are now defined by the <a href="https://crates.io/crates/alga">alga</a> crate.
All other mathematical traits, except <code>Axpy</code> have been removed from
<strong>nalgebra</strong>.</li>
<li>Methods are now preferred to free functions because they do not require any
trait to be used anymore.</li>
<li>Most algebraic entities can be parametrized by type-level integers
to specify their dimensions. Using <code>Dynamic</code> instead of a type-level
integer indicates that the dimension known at run-time only.</li>
<li>Statically-sized <strong>rectangular</strong> matrices.</li>
<li>More transformation types have been added: unit-sized complex numbers (for
2D rotations), affine/projective/general transformations with <code>Affine2/3</code>,
<code>Projective2/3</code>, and <code>Transform2/3</code>.</li>
<li>Serde serialization is now supported instead of <code>rustc_serialize</code>. Enable
it with the <code>serde-serialize</code> feature.</li>
<li>Matrix <strong>slices</strong> are now implemented.</li>
</ul>
<h3>Added</h3>
<p>Lots of features including rectangular matrices, slices, and Serde
serialization. Refer to the brand new <a href="https://nalgebra.rs">website</a> for more
details. The following free-functions have been added as well:</p>
<ul>
<li><code>::id()</code> that returns the universal <a href="https://nalgebra.rs/performance_tricks/#the-id-type">identity element</a>
of type <code>Id</code>.</li>
<li><code>::inf_sup()</code> that returns both the infimum and supremum of a value at the
same time.</li>
<li><code>::partial_sort2()</code> that attempts to sort two values in increasing order.</li>
<li><code>::wrap()</code> that moves a value to the given interval by adding or removing
the interval width to it.</li>
</ul>
<h3>Modified</h3>
<ul>
<li><code>::cast</code>            -&gt; <code>::convert</code></li>
<li><code>point.as_vector()</code> -&gt; <code>point.coords</code></li>
<li><code>na::origin</code>        -&gt; <code>P::origin()</code></li>
<li><code>na::is_zero</code>       -&gt; <code>.is_zero()</code> (from num::Zero)</li>
<li><code>.transform</code>        -&gt; <code>.transform_point</code>/<code>.transform_vector</code></li>
<li><code>.translate</code>        -&gt; <code>.translate_point</code></li>
<li><code>::dimension::&lt;P&gt;</code>  -&gt; <code>::dimension::&lt;P::Vector&gt;</code></li>
<li><code>::angle_between</code>   -&gt; <code>::angle</code></li>
