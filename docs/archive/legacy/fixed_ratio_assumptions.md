# Archived: Fixed 2:1 Mapping Assumptions

This document records legacy assumptions that treated the gear ratio as fixed (φ(θ) = 2θ) and enforced 2:1 via symmetry and hard-coded mappings. The system now supports a variable instantaneous ratio r(θ) with explicit no-slip and global constraints. Refer to `docs/variable_instantaneous_ratio_design.md` for the current model.
